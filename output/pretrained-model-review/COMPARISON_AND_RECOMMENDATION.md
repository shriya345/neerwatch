## CyFi evidence and important transfer limitations

The exact commits, file inventories, model sizes and SHA-256 hashes are saved in `repository-evidence.json`. Source paths below refer to the cloned repositories under `research/pretrained-review/`:

- `cyfi/cyfi/pipeline.py:250`: loads text boosters and configuration from ZIP. `:302` onward averages log-space predictions; density is transformed and rounded. `cyfi/cyfi/data/utils.py:57` onward implements log(1+density) and exp(log density)-1.
- `cyfi/cyfi/config.py:188` declares regression; `:219` specifies log_density. The **actual ZIP configurations and actual model headers** were inspected, rather than relying on these defaults alone.
- `cyfi/cyfi/data/satellite_data.py:34`, `:53`, `:67`: coordinate box, historical window and global catalogue. `:356` onward downloads native raster crops without explicit radiometric offset harmonization.
- `cyfi/cyfi/data/features.py:123`: SCL-based feature generation. Cloud fraction uses SCL 7–10 and a 5% limit. Water selection uses SCL 6, resized with OpenCV's default interpolation. It does not implement NEERWATCH's cloud/shoreline erosion buffers, polygon exclusion, or a minimum area-specific usable-pixel criterion. A box can include a different waterbody. Passing upstream QC is not equivalent to passing NEERWATCH QC.
- `cyfi/cyfi/data/features.py:205`: exact global C3S 2020 land-cover file. This is a required model feature, not a justified constant that can be filled with “water” simply because the requested site is a lake.
- `cyfi/cyfi/data/features.py:83`: batch-wise 1% winsorization. Reproducibility must specify candidate/batch composition. The isolated one-scene-per-point probe has one row per prediction, so this operation would not alter its features; it is not a full reproduction of the default 15-candidate search.
- `forecasting/models.py:1` onward contains explicit smoothing formulas; `forecasting/forecast.py:64` includes weekly backfilling. Reuse for causal forecasting would need its own leakage audit.
- Taiwan `notebooks/04_machine_learning_models.ipynb` imports and constructs classifiers; `03_dataset_preparation.ipynb:314` uses `train_test_split`. Actual artifact headers agree with classifier type.
- `water/app_water_extent.js:109` computes B3/B8 NDWI; `water/hls_water_extent.js:56` computes B3/B6 NDWI. Neither establishes trained algal regression.

### Radiometry is a real unresolved issue

CyFi's feature code uses stored raster values, whereas NEERWATCH's existing operational scenes have processing baseline 05.13 and explicit scale/offset metadata. Copernicus documents the baseline-04.00 introduction of the additive radiometric offset and its continuation in newer products: [official processing documentation](https://sentiwiki.copernicus.eu/web/s2-processing). This can shift means and ratios relative to older inputs. A model accepting the vector and returning a number does not resolve that compatibility question. We must identify the training imagery's actual encoding and test harmonization against the model before production use; simply supplying NEERWATCH's scaled reflectances would also be wrong.

### Scientific interpretation

The [CyFi paper](https://doi.org/10.25080/pdhk7238) describes a five-fold boosted-tree ensemble trained on 5,721 available U.S. observations and evaluated against 2,880 U.S. ground measurements. Those results establish an independently field-trained model, not its accuracy in Karnataka. No local MAE, RMSE, R², toxicity inference or public-health threshold performance can be reported without independent reference sampling. Changes in water optics, suspended sediment, species, season and sampling support can affect transfer.

A CyFi value is an estimated cyanobacterial cell density near a point using available imagery. It is not measured chlorophyll-a, observed FAI, phycocyanin concentration, measured biomass, a whole-reservoir average, or a future FAI prediction. Its default scene may precede the requested date by up to 30 days; any integration must display the actual acquisition date.

## Recommended architecture and decision

1. Keep the existing chlorophyll-a and observed FAI unchanged for exactly the current 46 reservoirs.
2. Treat CyFi as the only promising pretrained regression candidate among these four. Use an isolated, version-pinned worker with a private cache and a queue, rather than downloading imagery within synchronous API requests.
3. Before production integration, resolve radiometric compatibility, enforce same-reservoir spatial attribution, define accepted pixel coverage, verify the required land-cover feature and record scene dates and model hashes. More restrictive spatial masks change the model's feature distribution and also need evaluation.
4. If these gates pass, a later explicitly labelled **experimental pretrained cyanobacteria estimate** could satisfy a pretrained-regression demonstration. It must not be described as a model trained by NEERWATCH or validated in Karnataka. Faculty acceptance of pretrained reuse is a separate curricular decision.
5. Continue the existing historical acquisition unchanged. Random Forest future-FAI forecasting addresses a different task and still requires sufficiently broad chronological data, target-window purging, and comparison against persistence. Pretrained CyFi cannot remove that data requirement.

**Recommendation:** conditional GO for an isolated CyFi compatibility experiment; **NO-GO for production deployment as a validated Karnataka indicator at this stage**. Do not switch to the other three repositories merely to claim ML integration. See the proof-of-concept results for what actually executed and any remaining execution blockers.

### Measured compatibility checks from the isolated probe

The diagnostic SCL-grid overlay finds 99.494% of KRS water pixels, 99.994% of Bhadra water pixels, and 99.002% of Tungabhadra water pixels inside their existing reservoir polygons. This checks location attribution only; it does not establish radiometric or biological accuracy. The upstream box mask is retained for the probe, so the remaining outside pixels are disclosed rather than silently removed. Details are in `research/pretrained-review/poc/spatial-qc.json`.

Current raw B11 means are approximately 1472.78 (KRS) and 1225.07 (Bhadra), above the first model's stored training-feature maximum of 1118.40. KRS B02 is also above that model's stored maximum. The complete per-model range audit is `feature-range-check.json`. Range exceedance is not by itself proof that every prediction is wrong, but reinforces the need for encoding/transfer checks. No corrective feature transformation is approved by this investigation.
